DATABASE RELATIONSHIPS SUMMARY:
-------------------------------
1. Users to Orders (1:N): A user can place multiple orders, but each order belongs to only one user.
2. Users to Cart (1:N): A user can have multiple items in their cart.
3. Products to Cart (1:N): A specific product can be added to the carts of many different users.
4. Orders to Order_Items (1:N): One order contains multiple line items (products).
5. Products to Order_Items (1:N): A product can appear in many different order items across various orders.
6. Orders to Payments (1:1): In this system, each order is linked to a single payment record that tracks the transaction status (Completed/Pending).
7. Users to Payments (1:N): A user can have multiple payment records associated with their various orders.

KEYS LEGEND:
------------
- PK (Primary Key): Unique identifier for each record.
- FK (Foreign Key): Creates a link between tables (e.g., user_id in the orders table links back to the users table).
- UK (Unique Key): Ensures data (like email) is not duplicated.
